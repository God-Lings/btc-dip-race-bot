A dip-buying bot that trades cbBTC/USDC on 1-minute bars for the [make.fun BTC 24h race](https://make.fun/bounty/btc-race-24h-20261117-0603): it buys when the close dips 1.1% below the trailing 60-bar high and sells on a 1.0% recovery or a 1.0% stop-loss, long only and full size.

Run it with: `node main.ts`
